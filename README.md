# Café Esquina

Sitio web de ejemplo para una cafetería. Incluye inicio con carrusel, carta de productos y formulario de contacto.

## Estudiante
Escribí acá tu nombre.

## Cómo verlo
Abrí `index.html` en un navegador. No hace falta instalar programas.

## GitHub Pages
Cuando publiques el sitio, agregá acá el enlace.

Las ilustraciones de `images` se hicieron para este proyecto. Cambiá los nombres, precios, dirección y horarios de ejemplo antes de entregar.
